# Migrations log

This folder is the source of truth for every schema/RLS change ever run against
the Supabase database, in the order they were run. If you ever need to rebuild
the database from scratch, running these files in order (001, 002, 003, ...)
gets you there.

**Convention:** `00X_short_description.sql` — numbered sequentially, never
reordered or renumbered after the fact. When you write a new one, paste it
into the Supabase SQL Editor, run it, then add a row to the log below.

Data *imports* (one-off scripts that insert rows, like the Discogs collection
import or the Sessions history import) live in `../import/` instead — that
folder is for generated, re-runnable scripts, not hand-written schema changes.
